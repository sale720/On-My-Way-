# CHANGELOG

## [0.3.0] — 2026-10-31 — المرحلة 2: MVP التشغيلي
### أضيف
- الكتالوج: فئات (إدارة المنصة) وخدمات المنشأة بأسماء عربية/إنجليزية وسعر بالهللة ومدة.
- الجغرافيا: مدن وأحياء، تغطية بمستويين (منشأة + مقدمة خدمة) مع رسوم انتقال لكل حي، وأسباب عدم أهلية مُفسّرة.
- عناوين العميلات (حذف ناعم)، وإخفاء العنوان الكامل عن المنشأة حتى التأكيد.
- الجداول: ساعات عمل أسبوعية، أيام إجازة، محرك مواعيد يراعي وقت الانتقال والمهلة الدنيا وأفق الحجز (توقيت الرياض).
- الحجز: 17 حالة ومخطط انتقالات صريح بالصلاحيات، لقطات السعر/العنوان/السياسة، منع التعارض بقيد PostgreSQL، مهلة قبول، سياسة إلغاء مجاني، سجل حالات.
- التسعير: خدمة + انتقال + ضريبة، وعمولة منصة قابلة للتهيئة (افتراضياً 0).
- الدفع: جميع الوسائل السبع مضافة وظاهرة وقابلة للتبديل؛ النقد فعلي مع تأكيد الاستلام؛ واجهة `PaymentGateway` جاهزة للربط.
- التقييمات (مرة لكل حجز مكتمل)، الإشعارات داخل التطبيق، تقرير المنصة.
- واجهات: الحجز للعميلة، إدارة المنشأة، لوحة الإدارة (كتالوج ومناطق، رسوم ووسائل دفع، تقارير).
- 36 اختبار وحدة/تكامل جديد و11 خطوة E2E جديدة.

## [0.2.0] — 2026-10-31 — المرحلة 1: الأساس التقني
### أضيف
- دخول برقم الجوال + OTP (HMAC، 5 محاولات، حدود معدل لكل رقم وIP، رمز واحد صالح).
- جلسات مخزّنة في PostgreSQL (رمز مُجزّأ)، تسجيل خروج يلغي الجلسة على الخادم.
- RBAC: أدوار منصة (CUSTOMER, PROVIDER, SUPPORT_AGENT, PLATFORM_ADMIN) وأدوار منشأة (OWNER, MANAGER, STAFF).
- المنشآت (الصالون السحابي) مع عزل كامل بين المستأجرين، وإدارة الأعضاء، وحماية آخر مالكة.
- لوحة إدارة: المستخدمون (تعليق/تفعيل، منح/سحب أدوار مع سبب)، المنشآت (تغيير الحالة)، سجل التدقيق.
- سجل تدقيق لكل إجراء حساس داخل نفس المعاملة.
- واجهة عربية/إنجليزية مع RTL/LTR، واللغة محفوظة لكل مستخدم.
- التحقق من الإعدادات (`env.ts`)، سجلات JSON مع إخفاء الأسرار.
- قاعدة اختبار منفصلة، 51 اختبار وحدة/تكامل، 12 سيناريو E2E، CI على GitHub Actions.
- سكربت `admin:grant` لتهيئة أول مدير منصة.
