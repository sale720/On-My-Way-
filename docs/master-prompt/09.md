## 23. مراحل التنفيذ وخطة التسليم

يجب تقسيم التنفيذ إلى مراحل واضحة. التواريخ التالية تقديرات تخطيطية أولية وليست التزاماً زمنياً، ويجب تعديلها بناءً على حجم الفريق والتقنيات الحالية.

### المرحلة صفر: تحليل المنتج والتخطيط

الهدف:
إزالة الغموض قبل البناء.

المخرجات:

* مراجعة المستودع الحالي.
* وثيقة BRD.
* وثيقة FRD.
* Personas.
* User Journeys.
* User Stories.
* Acceptance Criteria.
* مخطط تدفق الحجز.
* مخطط انتقال حالات الحجز.
* مخطط ERD.
* Architecture Diagram.
* سجل الافتراضات.
* سجل المخاطر.
* قائمة التكاملات.
* خطة مراحل التنفيذ.
* قائمة ما يدخل في MVP وما يؤجل.

شروط الإكمال:

* تحديد المستخدمين والصلاحيات.
* توثيق قواعد التغطية.
* توثيق قواعد التسعير.
* توثيق دورة الحجز.
* تحديد نموذج الدفع.
* تحديد الافتراضات غير المحسومة.

### المرحلة الأولى: الأساس التقني

الهدف:
إنشاء البنية الأساسية الآمنة والقابلة للتوسع.

المخرجات:

* هيكل المشروع.
* قاعدة البيانات.
* نظام المصادقة.
* إدارة الأدوار والصلاحيات.
* الفصل بين المنشآت.
* إدارة المستخدمين.
* إعدادات اللغة.
* دعم RTL وLTR.
* نظام السجلات والأخطاء.
* إعدادات البيئة.
* Migration Scripts.
* اختبارات أساسية.
* CI/CD عند توفر بيئة مناسبة.

شروط الإكمال:

* إنشاء حساب وتسجيل الدخول.
* التحقق من الصلاحيات.
* استمرار البيانات بعد إعادة التشغيل والنشر.
* عدم كشف بيانات منشأة لمستخدم من منشأة أخرى.
* نجاح الاختبارات الأساسية.

### المرحلة الثانية: MVP التشغيلي

الهدف:
إطلاق نسخة محدودة قابلة لاختبار السوق والتشغيل.

الوظائف:

* تطبيق العميلة أو واجهة جوال مناسبة.
* ملف مقدمة الخدمة.
* ملف المنشأة.
* كتالوج الخدمات.
* إدارة العناوين.
* إدارة نطاق التغطية الأساسي.
* التحقق الجغرافي.
* إدارة جدول العمل.
* محرك توافر أساسي.
* إنشاء الحجز.
* قبول أو رفض الحجز.
* إدارة حالات الحجز.
* تسعير أساسي.
* إدارة رسوم الانتقال.
* الدفع في بيئة اختبار، ثم تفعيل مزود حقيقي عند الإعداد.
* الإشعارات الأساسية.
* لوحة الإدارة.
* سجل حجوزات.
* التقييمات الأساسية.
* التقارير الأساسية.

شروط الإكمال:

* يمكن للعميلة البحث عن خدمة في عنوانها.
* تظهر الخيارات المؤهلة فقط.
* لا يمكن تأكيد حجز متعارض.
* تظهر الرسوم الإجمالية قبل التأكيد.
* يمكن تتبع حالة الحجز.
* يمكن إدارة المستخدمين والخدمات من لوحة الإدارة.
* لا تضيع البيانات بعد إعادة نشر التطبيق.

### المرحلة الثالثة: التغطية الجغرافية المتقدمة والتشغيل

الهدف:
تحويل التغطية من فلتر بسيط إلى محرك قرار تشغيلي.

الوظائف:

* دعم مناطق متعددة.
* رسم نطاقات جغرافية.
* دعم الاستثناءات.
* نطاق منفصل لكل مقدمة خدمة.
* قواعد حسب اليوم والوقت.
* رسوم بحسب المنطقة.
* التكامل مع Routing وETA.
* حساب وقت الانتقال.
* منع التعارضات الجغرافية والزمنية.
* الطلبات العاجلة.
* إعادة الإسناد.
* تعديل التغطية المؤقت.
* إدارة حالات التأخير وعدم الوصول.

شروط الإكمال:

* يمكن تفسير سبب قبول أو رفض الطلب.
* إعادة التحقق قبل تأكيد الحجز.
* لا تُلغى الحجوزات المؤكدة بسبب تغيير نطاق التغطية وحده.
* لا يعرض النظام ETA فعلياً دون تكامل أو بيانات تدعمه.
* يمكن اختبار الحالات الجغرافية على بيانات اصطناعية.

### المرحلة الرابعة: SaaS وإدارة المنشآت

الوظائف:

* إدارة أعضاء الفريق.
* توزيع الصلاحيات.
* إدارة الخدمات والأسعار.
* إدارة حجوزات Marketplace والحجوزات المباشرة.
* إدارة العملاء المباشرين.
* تقارير المنشأة.
* إدارة العروض.
* الاشتراكات وخططها عند اعتماد النموذج التجاري.
* إدارة المستحقات.
* فصل بيانات كل منشأة.

شروط الإكمال:

* تستطيع المنشأة إدارة عملياتها دون الاعتماد الكامل على Marketplace.
* لا يستطيع عضو الاطلاع على بيانات غير مخول بها.
* يمكن التمييز بين مصادر الحجز.
* تقارير المنشأة مرتبطة ببياناتها الفعلية.

### المرحلة الخامسة: المدفوعات والتسويات المتقدمة

الوظائف:

* تكامل الدفع الحقيقي.
* معالجة Webhooks.
* الاسترداد الكامل والجزئي.
* إدارة العمولات.
* تسويات المنشآت.
* الفواتير.
* المطابقة المالية.
* سجل مالي تدقيقي.
* تقارير المستحقات.

شروط الإكمال:

* لا تتكرر العملية المالية عند تكرار الحدث.
* يمكن تتبع كل مبلغ إلى الحجز المرتبط.
* يمكن تفسير حساب العمولة وصافي المستحقات.
* حالات الفشل والاسترداد موثقة ومختبرة.
* تم اختبار التكامل في بيئة مزود الدفع.

### المرحلة السادسة: المخزون والربحية والتحليلات

الوظائف:

* إدارة المواد والمستهلكات.
* ربط المواد بالخدمات.
* إدارة حقائب مقدمي الخدمة.
* تسجيل الاستهلاك.
* احتساب التكلفة المباشرة.
* تقارير الربحية.
* تحليل المناطق.
* قياس تكلفة التنقل.
* تحليل أسباب الإلغاء.
* تقارير الأداء.
* تنبيهات تشغيلية.

شروط الإكمال:

* يمكن ربط التكاليف المسجلة بالحجز.
* لا تُعرض التقديرات على أنها أرقام مالية فعلية.
* يمكن تحديد مصدر كل مؤشر ومعادلة احتسابه.

### المرحلة السابعة: الأتمتة والتحسين

الوظائف المحتملة:

* تحسين ترتيب النتائج.
* التنبؤ بالطلب.
* اقتراح مناطق توسع.
* تحسين توزيع الحجوزات.
* تحسين المسارات.
* اقتراح تجميع الخدمات.
* برامج الولاء.
* الطلبات الجماعية للمناسبات.
* تكاملات إضافية.
* أدوات دعم أكثر تقدماً.

هذه المرحلة تأتي بعد وجود بيانات تشغيلية موثوقة، وليست شرطاً لإطلاق MVP.
