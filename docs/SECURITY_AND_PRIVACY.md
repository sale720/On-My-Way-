## قيود معروفة (يجب معالجتها قبل الإنتاج)
- `X-Forwarded-For` يُستخدم لتحديد IP؛ موثوق فقط خلف Proxy يعيد كتابة الترويسة.
- لا توجد ترويسات أمان مخصّصة بعد (CSP, HSTS) — تُضاف مع إعداد النشر.
- لا تشفير على مستوى الحقول (الأرقام نص واضح في القاعدة) — يُقيَّم مع متطلبات نظام حماية البيانات الشخصية (PDPL) قبل الإطلاق.
- لا سياسة احتفاظ/حذف آلية للـ OTP والجلسات المنتهية بعد.
- الامتثال القانوني (PDPL، التجارة الإلكترونية) **لم يُقيَّم قانونياً**؛ لا ادعاء امتثال.
