# On My Way — مواصفات النسخة الأولى (MVP)

> **ملاحظة:** هذه مسودة أولية سابقة للمرجع الأعلى [`MASTER_PROMPT.md`](MASTER_PROMPT.md). عند التعارض يُعتمد المرجع، وستُستبدل هذه الوثيقة بوثائق BRD/FRD المشتقة منه.

## 1. الهدف
منصة تربط **العميلات** بـ**مقدّمات خدمات الصالون المنزلي** (حجز، مواعيد، تقييم)، مع بنية قابلة للتوسّع لقطاعات أخرى عبر جدول `Category` بدل تثبيت "صالون" في الكود.

## 2. الأدوار (Roles)
| الدور | الصلاحيات الأساسية |
|---|---|
| `CUSTOMER` | تصفّح الخدمات، حجز موعد، إلغاء، تقييم بعد الإنجاز |
| `PROVIDER` | إدارة الملف والخدمات والأسعار، تحديد أوقات التوفّر ومنطقة الخدمة، قبول/رفض الحجوزات |
| `ADMIN` | اعتماد مقدّمات الخدمة، إدارة التصنيفات، مراقبة الحجوزات والتقييمات |

## 3. تدفّق الحجز (Booking lifecycle)
```
PENDING ──(قبول المقدّمة)──> CONFIRMED ──(بدء الزيارة)──> IN_PROGRESS ──> COMPLETED ──> (تقييم)
   │                              │
   └──(رفض/انتهاء المهلة)──> REJECTED   └──(إلغاء)──> CANCELLED
```
قواعد:
- لا يُقبل حجز يتداخل مع حجز `CONFIRMED`/`IN_PROGRESS` لنفس المقدّمة (يُتحقّق في الخادم داخل transaction).
- التقييم مسموح مرة واحدة لكل حجز، وفقط بعد `COMPLETED`.
- يُحفظ سعر الخدمة ومدتها **وقت الحجز** (snapshot) حتى لا يتأثر الحجز بتعديل الأسعار لاحقاً.

## 4. الكيانات (انظر `prisma/schema.prisma`)
`User`, `ProviderProfile`, `Category`, `Service`, `Availability`, `Booking`, `BookingItem`, `Review`, `Address`.

## 5. افتراضات (تحتاج تأكيد)
1. السوق المستهدف: السعودية/الخليج → العملة الافتراضية `SAR`، المنطقة الزمنية `Asia/Riyadh`، الواجهة عربية RTL أولاً.
2. الدفع: نقداً عند الزيارة في MVP؛ الدفع الإلكتروني (مثل Moyasar/Tap/HyperPay) في مرحلة لاحقة.
3. الدخول: برقم الجوال + OTP (يتطلب مزوّد SMS — لم يُحدَّد بعد).
4. التغطية الجغرافية: المقدّمة تحدّد مدناً/أحياء تخدمها (بدون خرائط في MVP).
5. الخصوصية: عنوان العميلة لا يظهر للمقدّمة إلا بعد `CONFIRMED`.

## 6. خارج نطاق MVP
الدفع الإلكتروني، العمولات والتسويات، التتبّع الحيّ على الخريطة، الإشعارات الفورية (Push)، تطبيق جوال أصلي.

## 7. خارطة الطريق
1. **الآن:** الهيكل + نموذج البيانات + واجهة RTL. ✅
2. المصادقة (OTP) + الأدوار.
3. لوحة المقدّمة: الخدمات والتوفّر.
4. البحث والحجز للعميلة + منع التداخل.
5. التقييمات + لوحة الإدارة.
