# محرك التغطية الجغرافية — حالة المرحلة 2

المصدر: `src/server/bookings/search.ts` (`evaluateService`)، `src/server/geo/service.ts`.

## النموذج الحالي: على مستوى الحي
- **مرجع جغرافي:** يضيف مدير المنصة المدن والأحياء من لوحة الإدارة، ولا توجد بيانات مزروعة. لم تُربط بعد حدود جغرافية رسمية (مضلّعات)، والمرجع §4.2 يطلبها في المرحلة 3.
- **المستوى 1 — نطاق المنشأة** (`SalonCoverageArea`): الأحياء التي تعمل فيها المنشأة، ولكل حي رسوم انتقال.
- **المستوى 2 — نطاق مقدمة الخدمة** (`StaffCoverage`): الأحياء التي تصلها كل مقدمة، ويجب أن تكون ضمن نطاق المنشأة.
- **قاعدة الأهلية:** يُعرض الخيار فقط إذا وقع حي العميلة ضمن **نطاق المنشأة ونطاق مقدمة خدمة واحدة على الأقل** تجيد الخدمة ولها جدول عمل وموعد متاح.

## أسباب عدم الأهلية (قابلة للتفسير)
| الرمز | المعنى |
|---|---|
| `SALON_NOT_ACTIVE` | المنشأة غير معتمدة |
| `SERVICE_INACTIVE` | الخدمة متوقفة |
| `OUT_OF_SALON_AREA` | الحي خارج نطاق المنشأة |
| `NO_STAFF_FOR_SERVICE` | لا مقدمة خدمة تقدم هذه الخدمة |
| `NO_STAFF_COVERS_AREA` | لا مقدمة خدمة تغطي الحي |
| `NO_STAFF_SCHEDULE` | لا جدول عمل |
| `NO_AVAILABILITY` | لا موعد متاح خلال 14 يوماً |

تُعرض هذه الأسباب للعميلة في البحث تحت «خيارات غير متاحة لعنوانك».

## المسافة وزمن الوصول
**غير مُنفّذ.** لا توجد مسافة ولا ETA لعدم ربط مزوّد خرائط، ولا يعرض النظام أي وقت وصول. وقت الانتقال الثابت (`travelBufferMinutes`) يُحجز قبل كل زيارة كتقدير معلن. المطلوب للمرحلة 3: Map Provider Adapter (Geocoding، Routing، Distance Matrix)، ومضلّعات، واستثناءات، وتغطية حسب اليوم والوقت، وتغطية مؤقتة.

## تعديل التغطية
تعطيل حي أو تغيير رسومه **لا يلغي** الحجوزات القائمة، ويمنع الطلبات الجديدة فقط. هذه القاعدة مختبرة.
