# التكاملات ومتطلبات تفعيلها

| التكامل | الحالة | ما المطلوب للتفعيل |
|---|---|---|
| SMS (OTP) | **غير متصل.** الواجهة جاهزة (`src/server/sms/provider.ts`). المتاح: `console` (تطوير) و`memory` (اختبار) فقط | اختيار مزوّد مرخّص في السعودية + بيانات اعتماد + اسم مرسل معتمد؛ كتابة Adapter يطبّق `SmsProvider`؛ إضافة القيمة إلى `SMS_PROVIDER` والسماح بها في الإنتاج داخل `env.ts`؛ اختبار في بيئة المزوّد |
| الخرائط/التوجيه | غير مبدوء (المرحلة 2–3) | — |
| الدفع | غير مبدوء (المرحلة 5) | — |
| البريد/Push | غير مبدوء | — |

> بدون مزوّد SMS حقيقي **لا يمكن** تشغيل البيئة الإنتاجية — هذا مقصود (`env.ts` يرفض التشغيل).
