# جرّب المنصة داخل GitHub (بدون سيرفرات)

المنصة تعمل في **GitHub Codespaces**: بيئة تشغيل مؤقتة داخل GitHub تفتحها من المتصفح، فيها التطبيق وقاعدة بيانات تجريبية خاصة بك.

> **وضع تجريبي بالكامل:** لا تُرسل رسائل SMS حقيقية، ولا تُنقل أموال حقيقية. كل البيانات المزروعة تجريبية ومُعلّمة بكلمة «تجريبي».

## 1) التشغيل (أول مرة: نحو 3–5 دقائق)
1. افتح المستودع على GitHub.
2. الفرع الافتراضي `main` يحوي آخر نسخة مختبرة. لتجربة ميزة قيد المراجعة اختر فرعها من قائمة الفروع.
3. اضغط زر **Code** ← تبويب **Codespaces** ← **Create codespace on …**.
4. انتظر حتى تنتهي التهيئة. يُثبَّت كل شيء ويُجهَّز التطبيق والبيانات التجريبية تلقائياً.
5. يعمل التطبيق على المنفذ **3000** ويفتح تلقائياً. إن لم يفتح: تبويب **PORTS** ← المنفذ 3000 ← أيقونة الكرة الأرضية.

إن توقف التطبيق، شغّله من الطرفية (Terminal):
```bash
npm run dev
```

## 2) تسجيل الدخول
1. صفحة **تسجيل الدخول** ← أدخل أحد الأرقام التجريبية أدناه ← **إرسال الرمز**.
2. اضغط رابط **«صندوق الرسائل التجريبي»** الظاهر في الصفحة، أو افتح `/dev/sms`، وانسخ الرمز المكوّن من 6 أرقام.
3. أدخل الرمز ← **تأكيد**.

| الرقم | الحساب | ماذا يجرّب |
|---|---|---|
| `0500000001` | مديرة المنصة | الإدارة: المستخدمون، المنشآت، الكتالوج والمناطق، الرسوم ووسائل الدفع، التقارير، سجل التدقيق |
| `0500000002` | مالكة «صالون النخبة» | إدارة المنشأة: الخدمات، التغطية، الفريق والجداول، الحجوزات، الإعدادات ووسائل الدفع |
| `0500000003` | نورة — مقدمة خدمة | قبول الطلبات وتنفيذ الزيارة، جدولها وأحياؤها |
| `0500000004` | ريم — مقدمة خدمة | مثل نورة، بمهارات وأحياء مختلفة |
| `0500000005` | سارة — عميلة | البحث والحجز والدفع والإلغاء والتقييم |

يمكنك أيضاً تسجيل الدخول بأي رقم جوال سعودي آخر (يبدأ بـ 05)؛ يُنشأ حساب عميلة جديد، ويظهر رمزه في الصندوق التجريبي.

## 3) سيناريو تجربة كامل (10 دقائق)
1. **العميلة (0500000005):** «احجزي خدمة» ← العنوان «المنزل» ← الفئة «الشعر» ← بحث ← اختيار ← يوم ← وقت.
2. في صفحة المراجعة تظهر **وسائل الدفع السبع**. الإلكترونية مكتوب بجانبها «تجريبي — بدون أموال حقيقية».
3. اختر **مدى**، ثم في بوابة الدفع التجريبية استخدم بطاقة الاختبار:
   - `4111 1111 1111 1111` ← دفع ناجح
   - `4000 0000 0000 0002` ← دفع مرفوض
4. بعد نجاح الدفع يُرسل الطلب لمقدمة الخدمة. اسمها (نورة أو ريم) ظاهر في تفاصيل الحجز؛ سجّل الدخول برقمها من الجدول أعلاه، وافتح الحجز من «الإشعارات» ← **قبول الطلب**.
5. نفّذ الزيارة: في الطريق ← وصلت ← بدء الخدمة ← إكمال الخدمة.
6. **العميلة:** قيّمي الخدمة. أو جرّبي إلغاء حجز مدفوع قبل موعده بأكثر من 24 ساعة ← يظهر **استرداد المبلغ**.
7. جرّبي عنوان «بيت الأهل» (حي العليا): لا تظهر خيارات، ويظهر **سبب** عدم التوفر.
8. **Apple Pay / STC Pay / تابي / تمارا:** أزرار «موافقة» أو «رفض» في البوابة التجريبية.

## 4) الإيقاف والتكلفة
- الخطة المجانية لحساب GitHub الشخصي تشمل شهرياً **120 ساعة-نواة** و**15 GB تخزين** لـ Codespaces. الجهاز ذو النواتين يستهلك ساعتين-نواة لكل ساعة تشغيل، أي نحو **60 ساعة استخدام فعلي شهرياً**. ([GitHub Docs — Plans](https://docs.github.com/en/get-started/learning-about-github/githubs-plans)، [Codespaces billing](https://docs.github.com/billing/managing-billing-for-github-codespaces/about-billing-for-github-codespaces))
- عند نفاد الحصة يتوقف الاستخدام، إلا إذا أضفت وسيلة دفع وحداً للإنفاق.
- **أوقف الـ Codespace بعد الانتهاء:** github.com/codespaces ← ⋯ ← Stop. البيانات تبقى حتى تحذفه.
- متابعة الاستهلاك: github.com/settings/billing.

## 5) تشغيل الاختبارات داخل الـ Codespace (اختياري)
```bash
npm test                          # 101 اختبار وحدة وتكامل على قاعدة اختبار منفصلة
npm run build && npm run test:e2e # اختبارات المتصفح الشاملة (تتطلب تثبيت Playwright أولاً)
```

## 6) إن واجهت مشكلة
| العرَض | الحل |
|---|---|
| الصفحة لا تفتح | تبويب PORTS ← 3000؛ أو `npm run dev` في الطرفية |
| خطأ اتصال بقاعدة البيانات | انتظر دقيقة بعد الإنشاء الأول، ثم `bash .devcontainer/setup.sh` |
| تريد بدء التجربة من الصفر | احذف الـ Codespace وأنشئ واحداً جديداً (يحذف البيانات التجريبية فقط) |

> لم يُختبر هذا الإعداد داخل Codespaces فعلياً من جهتنا؛ اختُبر سكربت التهيئة وتشغيل التطبيق على نسخة نظيفة مطابقة. إن ظهرت مشكلة في Codespaces أرسل لي رسالة الخطأ.
